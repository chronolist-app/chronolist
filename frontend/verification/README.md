# CHButtonの表示・操作確認

開発Frontendを起動して `/verification/chbutton.html` を開く。本番ルートには追加しない。
自動テストは `npm test`、表示とネイティブ操作はこのページで確認する。

MUIアイコンはSVG枠の内側に余白があるため、デスクトップのmdでは枠を14pxに補正している。
保存中のCircularProgressにも同じアイコン寸法を適用する。

- 600px以上と599px以下で5サイズの高さ・余白・文字・アイコン寸法を確認する。
- 9組の通常・hover・押下中・Tabフォーカスの色、2pxリングを確認する。
- disabledボタンがTab対象外で、押しても実行回数が増えないことを確認する。
- 長いラベルが200px幅で折り返され、文字200%でも切れず高さが広がることを確認する。
- アイコンと文字のまとまりが中央に並び、保存中のアイコンも指定寸法に収まることを確認する。
- クリックは送信せず、Enter/Spaceでも動作すること、送信とリセットが各カウンタと入力欄に反映されることを確認する。

実画面は `/timeblocking` の「ブロックを作成」で確認する。空の名前と不正な幅は保存せずエラーを表示する。
正しい入力を保存すると処理中表示・連打抑止・入力無効を維持し、成功時は閉じてブロックを追加する。
通信失敗時はエラーを表示して入力内容を維持し、再操作できることを確認する。
